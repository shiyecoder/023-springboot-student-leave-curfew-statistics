# 设计系统 · 学生请销假与晚归统计管理系统（NEW-023）

## 1. 视觉方向

企业海军蓝的校内业务系统。信息密度高、状态辨识清晰、操作路径短。不使用巨幅英文口号、装饰光效、悬浮球与大插画；卡片圆角 6–8px，阴影只用于抽屉/弹窗。

## 2. 色彩

| 语义 | 色值 | 用途 |
|---|---|---|
| 主色 primary | `#1F2937` | 顶栏、主按钮、当前菜单、关键数字 |
| 辅助色 secondary | `#2F6B8A` | 次级按钮、筛选选中、普通图表系列 |
| 强调色 accent | `#3B627A` | 链接、信息提示、对比图表系列 |
| 页面背景 | `#F5F7FA` | 内容区背景，白色容器承载表格与表单 |
| 分割线 | `#E3E8EF` | 卡片、表格、表单边界 |
| 正文 | `#1F2937` | 主文本 |
| 次要文本 | `#6B7785` | 标签、说明、时间 |
| 成功 | `#2E7D5B` | 已通过、已销假、正常 |
| 警告 | `#A9761F` | 待审批、待销假、即将超期 |
| 危险 | `#B3261E` | 驳回、超期、异常、删除确认（仅小面积） |

状态指示必须同时有中文标签，不允许只用颜色区分。

## 3. 字体阶梯

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| H1 | 18 / 26 | 600 | 页面标题 |
| H2 | 14 / 22 | 600 | 卡片标题 |
| Body | 13 / 20 | 400 | 表格、表单 |
| Small | 12 / 18 | 400 | 标签、筛选 label |
| Micro | 11 / 16 | 400 | 图例、脚注 |
| KPI | 24 / 32 | 600 | 指标数值，`font-variant-numeric: tabular-nums` |

中文使用系统字体：`-apple-system, "PingFang SC", "Microsoft YaHei"`；所有时间、编号、天数、分数使用等宽数字特性。

## 4. 间距与栅格

- 基准 4px 栅格；页面外边距 24px，卡片内边距 16px，卡片间距 16px
- 侧边栏 220px（折叠 64px），顶栏 56px
- 表单标签宽 100–120px，输入宽度 360–520px；搜索下拉 180–240px
- KPI 卡片 6 列（1440 宽），详情分组 2 列，图表区 2–3 列

## 5. 圆角与阴影

- 卡片/表格容器 6px；按钮 4px；标签 3px；抽屉 6px；头像圆形
- 卡片默认无阴影，仅 1px 边框；抽屉 `0 8px 24px rgba(31,41,55,.12)`

## 6. 角色视觉区分

| 角色 | 视图定位 | 首页结构 | 主色使用 |
|---|---|---|---|
| 学生 | 请假门户 | 4 指标 + 未完成单据 + 安全提示 | 主色按钮 + 蓝底提示条 |
| 辅导员 | 审批台 | 5 指标 + 待办列表 + 抽屉审批 | 主色 + 警告色强调时效 |
| 院系负责人 | 学工管理 | 5 指标 + 趋势/时效图 + 班级排行 | 主色 + 灰色对比系列 |
| 宿管值班员 | 值班台 | 双栏：登记表单 + 当班记录 | 主色 + 成功色通过态 |
| 管理员 | 系统治理 | 6 指标 + 6 图表一屏 | 主色 + 派生图表色 |

## 7. 图表规范

- 系列色：`#1F2937` / `#2F6B8A` / `#3B627A` / `#9AA8B6`，同一含义跨页一致
- 折线仅 2px 描边，无填充面积；柱状圆角 2px；环图内径 56%
- 图表必须可点击下钻到对应筛选的列表
- 首页 1440×900 一屏内完成，不出现需要连续下滚才能看全的情况
